# Age Calculator

A small browser-based age calculator. Choose a birthdate from the date picker and the app displays your age in years and months.

## Features

- Select a birthdate with a calendar date picker.
- Calculate age in years and months.
- Show a message if no date is selected or the selected date is in the future.

## Run locally

1. Clone or download this project.
2. Open `index.html` in a modern web browser.
3. Select your birthdate and click **Calculate Age**.

The page loads the date picker and Luxon from CDNs, so an internet connection is needed when opening the app.

## Project files

- `index.html` — app markup and external library references.
- `script.js` — date selection and age calculation.
- `style.css` — page and date picker styles.
- `package.json` — JavaScript library dependency declarations.
